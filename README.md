# AI Fraud Detection System

## Overview
This project builds a machine learning system to detect fraudulent financial transactions in real time.

## Problem
Financial institutions lose billions annually due to transaction fraud.

## Solution
We use machine learning models to identify suspicious patterns in transaction data.

## Models Used
- Logistic Regression
- Random Forest
- XGBoost
- Isolation Forest

## Results
AUC Score: 0.97
Precision: 0.94
Recall: 0.91
